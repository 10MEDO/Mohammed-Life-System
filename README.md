# Mohammed Life System

A bilingual personal life-management web app.

## Features

- English / Arabic toggle with RTL support
- Automatic daily records
- Previous / next day navigation
- Local persistent storage in the browser
- Sleep, prayer, study, walking, reading, water and screen-time tracking
- Neck / shoulder / back symptom tracking
- Daily goals and habits
- Finance and phone-savings target
- History and 30-day analytics
- JSON export/import for backups

## Run

Open `index.html` in a modern browser.

## GitHub Pages

This is a static app, so it can be deployed with GitHub Pages. Enable Pages for the repository and use the `main` branch root as the source.

## Important

The app stores data in the browser's localStorage. Use **Export data** regularly for backups. Health fields are tracking tools, not medical diagnosis.
